整理者：曲宸宇（Chu, Chen-Yu；GitHub：poplolioi11；[ORCID](https://orcid.org/0009-0003-9738-6914)）。歷史作品與現代資料整理者分開。

本成果為1859年博濟醫局刊《種痘捷法》的醫學史文獻數位化資料，提供原文定位、檢索、引用與後續校訂。保留歷史原文，不另編寫歷史技法的實作摘要。

底本為Bodleian Libraries Sinica 1240。來源共8影像幀，含10內頁物理面，其中9面有原印文字；影像幀數不是葉數。p02題頁透印不重錄；封面與現代館藏注記僅描述。版心及頁碼只錄固定初錄實見字，不以他面補字。現有固定掃描未見清晰獨立圖式，沒有補畫。

本包含69個原初錄欄文／標題單位及15個實見版心／頁碼單位，合計84單位、1187個Unicode碼點、4筆定位疑讀。碼點數不是漢字數、疑讀數不是錯誤率。後續獨立AI盲讀及回圖校讀須另發v0.2.0，不回寫本版。

## English summary

An initial AI transcription of *Zhong dou jie fa*, an 1859 Chinese medical-history booklet held as Bodleian Sinica 1240. It provides source-linked text, JSON and TEI for historical-document discovery, citation and later correction. Eight image frames contain ten interior physical faces, nine with original print. Later library annotations and title-page bleed-through are excluded from the historical text. There has been no independent collation, human double proofreading, expert review or measured character accuracy for this version. Images and private processing materials are not redistributed.
